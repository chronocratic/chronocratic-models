**Breaking:** removed the `Reseedable` protocol (`chronocratic.models.augmentation.Reseedable`) and `CropShiftProducer.reseed()`. Producers draw from the global torch generator, which `Seeded` already seeds through `torch.manual_seed`, so the extra NumPy hook is no longer needed. Custom producers that implemented `reseed()` should draw with `torch.randint`, `torch.rand` and similar instead; wrapping them in `Seeded` then makes them deterministic with no further code.
