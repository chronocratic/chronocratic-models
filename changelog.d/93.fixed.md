TimeVAE no longer allocates an O((C·T)²) dense layer in its residual decoder by default; training memory at T=5200, C=5 (DuckDuckGeese) drops from ~10.5 GB (measured) to ~0.51 GB (measured), and parameter count drops from ~678M to ~3.4M. Series2Vec computes soft-DTW targets in O(T) memory per pair instead of keeping the full T×T table for every pair in the batch; at T=7500 (EigenWorms), batch size 4 drops from ~7.4 GB (measured, spec §3.2) to ~0.62 GB (measured) and batch size 8 drops from ~28-31 GB (measured, spec §3.2) to ~0.77 GB (measured). Series2Vec batches of size 2 now split into windows so the pairwise loss has a gradient instead of being exactly zero.
