Fixed SimCLR pretraining making no progress: the loss sat at `log(2N - 1)` — the value a contrastive loss takes when every logit is equal — from the first step onward. The ResNet-1D backbone global-average-pooled over time before returning, which left every sample pointing in nearly the same direction; NT-Xent compares only angles, so it had no gradient to follow. The backbone now returns its unpooled `(B, C, T')` feature map and the contrastive path projects each timestep and concatenates, matching the reference, which flattens `C × T` rather than pooling. `encode()` owns the temporal reduction instead: `VECTOR` averages over time and is numerically unchanged, so `representation_dim` and every downstream probe are unaffected, while `SEQUENCE` now returns a real `(B, T', C)` temporal axis rather than the length-1 placeholder and its accompanying warning. Replacing the average with a maximum, as first proposed, was measured and does not help — reducing the temporal axis to a point at all is what removes the signal, not the choice of reduction.
