fix(simclr): decouple pooling from encoder so NT-Xent can learn: SimCLR pretraining was frozen: the loss sat at `log(2N-1)` from step zero because the encoder pooled over time before returning, leaving every sample pointing in nearly the same direction. NT-Xent compares only angles, so it had no gradient to follow. The encoder now returns its unpooled `(B, C, T')` feature map. The contrastive path projects per timestep and concatenates, preserving angular diversity. `encode()` owns the reduction: `VECTOR` averages over time (numerically unchanged), `SEQUENCE` transposes to `(B, T', C)` (real temporal axis, no more warning).
