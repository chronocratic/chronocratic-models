fix(models): cut TimeVAE and Series2Vec training memory: - TimeVAE: new `residual_projection` option (`crop` default, `dense` = upstream) removes the residual decoder's O((C·T)²) `final_dense` layer — 678M → 3.4M params, ~10.5GB → ~0.51GB training memory at T=5200, C=5 (measured, DuckDuckGeese shape). - Series2Vec: new `pairwise_soft_dtw_values` computes soft-DTW temporal targets in O(T) memory per pair (two rolling DP columns, no gradient) instead of keeping the full T×T table for every pair at once — T=7500 (EigenWorms) B=4 ~7.4GB → ~0.62GB, B=8 ~28-31GB → ~0.77GB (measured). New optional `soft_dtw_bandwidth` for further speed/accuracy trade-off. - Series2Vec: batches of size 2 now split into windows via `ensure_pairable_batch(min_batch_size=...)` so the pairwise loss carries gradient instead of silently training with loss exactly 0.0.
