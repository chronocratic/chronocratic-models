Moved `Conv1dResNetEncoder` and its residual blocks out of `chronocratic.models.convolutional.standard.simclr`, now that MHCCL is a second consumer: general-purpose blocks live in `chronocratic.models.convolutional.standard.layers.residual` and the named architecture that assembles them in `chronocratic.models.convolutional.standard.encoders.resnet`. Import `Conv1dResNetEncoder` from the latter instead. The encoder also gained `stem_conv_kernel_size`, which lets the stem convolution use a different kernel size from the residual convolutions; it defaults to `None` and falls back to `conv_kernel_size`, so existing configurations, `state_dict` shapes and checkpoints are unaffected.
