  <name>Task 1: Enforce kw-only on all multi-param functions</name>
  <files>
  </files>
  <action>
    Across the ENTIRE src/chronocratic/models/ tree, enforce kw-only params for any function/method with 2+ user-visible parameters. Single-obvious-param methods like `encode(x)`, `forward(x)`, `__call__(x)`, `transform(x)` may keep that input positional — no need to force kw-only when there's only one arg and it's obvious. The rule: if 2+ params exist, add `*` after any single obvious positional input to force the rest kw-only. This applies to:

    1. All model __init__: mcl, tstcc, ts2vec, autotcl, cost, series2vec, tst, timenet, timevae, recurrentae — must be `def __init__(self, *, ...)`
    2. All encoder __init__: mcl/encoder.py, tstcc/encoder.py, encoders/encoders.py, series2vec/network.py, recurrentae/layers.py — must be `def __init__(self, *, ...)`
    3. All model methods with multiple params: _encode_batch(x, *, output=...), training_step(*, batch, batch_idx), configure_optimizers() — enforce `*,` before the 2nd param
    4. All loss function __init__ and multi-param methods: every loss.py — enforce `*,` if 2+ params
    5. All factory functions: supervised/factory.py (make_tst_supervised, etc.) — must be `def func(*, backbone, ...)`
    6. All adapter functions: supervised/_adapters.py — enforce `*,` if 2+ params
    7. All utility/helper functions: models/utils/*.py — enforce `*,` if 2+ params
    8. All training strategies: autotcl/training.py — enforce `*,` if 2+ params
    9. All augmentation __init__ and multi-param methods — enforce `*,` if 2+ params
    10. All mixin multi-param methods — enforce `*,` if 2+ params

    Exceptions (single-param stays positional): `forward(x)`, `encode(x)`, `__call__(x)`, `transform(x)`, `decode(x)`, `sample(x)` — any method with exactly one obvious tensor/sequence input.

    For each multi-param function: add `*` after `self` (for __init__) or after the single obvious positional (for methods). Ensure all callers use keyword args.
  </action>
  <verify>
    <automated>uv run pytest tests/ -x -q</automated>
  </verify>
  <done>
    - All __init__ methods use `def __init__(self, *, ...)` — zero positional params

    - All multi-param methods/helpers use kw-only after single obvious positional
    - Single-param methods (encode, forward, __call__) may stay positional
    - Full test suite passes after kw-only enforcement
  </done>
